This module extends the sale order to overwrite
``action_quotation_send`` and ``action_cancel`` to prevent mail sendind
before validation.

.. contents::
   :local:

Usage
=====

To use this module, you need to:

-  Configure Tier Definitions for Sale Order
-  When the user try to send by email or cancel, the module search for
   definitions and prevent mail sendind before validations.
