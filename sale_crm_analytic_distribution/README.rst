This module propagates the analytic account set on a CRM opportunity
(e.g. created by ``crm_stage_analytic_account``) to the analytic
distribution of the quotation created from that opportunity, using the
header-level distribution added by ``sale_analytic_global``.

**Table of contents**

.. contents::
   :local:

Usage
=====

- Make sure the opportunity has an analytic account set
  (``Analytic Account`` field on the opportunity form).
- Click **New Quotation** on the opportunity.
- The new quotation's **Analytic Distribution** field (added by
  ``sale_analytic_global``) is automatically filled with the
  opportunity's analytic account, and propagated to the order lines once
  saved.
